# Catalog schema checks

Run `npm ci --ignore-scripts` once at the repository root, then `node --test scripts/schema-check/test/*.test.mjs`. Ajv 8.20.0 and ajv-formats 3.0.1 are pinned development dependencies with a lockfile; neither is imported by the extension, website worker or publisher runtime. The [Ajv draft-2020-12 implementation](https://ajv.js.org/json-schema.html#draft-2020-12) compiles the checked-in schemas with strict mode, full date-time validation, no coercion/defaults/property removal and no remote schema fetches.

The suite checks legacy manifest v1, catalog manifest v2 and catalog packet v2. It exercises valid profile/Unicode/source boundaries, recursively replaces fields with wrong JSON types, removes fields and adds unknown fields, and requires the runtime to refuse every schema-invalid mutation. Timestamp cases cover explicit timezone syntax, calendar dates and leap-second boundaries; the schemas constrain syntax because the format plugin also accepts some permissive non-contract spellings. Unicode limits count code points as JSON Schema defines, including on the extension's source RPC.

Schema validation is not signature trust, source certification or permission to play. Separate cases deliberately pass JSON Schema and fail runtime checks for cross-field timeline/source relationships, action flags, version ranges, required bindings, duplicate paths, Windows reserved filenames and minimum v2 client version. Cryptographic trust, byte budgets, cumulative file size, installed decoding, live policy and source observations remain enforced by their existing runtime tests and acceptance checks. This finite corpus does not prove universal equivalence of the schema and validator languages.

The initial comparison exposed string coercion in identifier/hash checks, permissive date-only timestamps and UTF-16/code-point length disagreement. Runtime checks now enforce the declared types/date-time and text bounds. A non-array `segments` object can no longer supply an arbitrary loop length. Valid existing fixtures and separate legacy/v2 trust modes remain covered; no test corpus is a published release.
